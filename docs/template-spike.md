## 発見事項

- 空のプレースホルダーには `a:t` が存在しないため、レイアウト書式を継承する新しいテキストランを作る必要がある。
- 同一スライド内でシェイプ名が重複するため、編集対象の確定には `shape_id` を併用する。
- このテンプレート単体ではSmartArt、グラフ、埋め込みExcelの更新要件を検証できない。各要素を含む代表サンプルを別途用意する。
- Visual Deck独自の下部フッターと右上ページ番号はブランド合成時に抑制し、テンプレートのロゴ、著作権表記、ページ番号との二重表示を避ける。
