# ADR 0006: 導入環境既定テンプレート

## 状態

採用

## 背景

利用者が新規資料のたびに同じ組織テンプレートを添付し、解析完了を待つ運用は負担が大きい。一方、pptx-mcpはOSSであり、特定企業のテンプレート、社名、ロゴ、利用者向け文言を本体へ含められない。

## 決定

- OSS本体には、外部テンプレートディレクトリ、既定テンプレートID、初回assistant案内という任意設定だけを設ける。
- 実際のPPTXと案内文は導入環境が管理し、コンテナへ読み取り専用で渡す。
- 既定テンプレートは起動時に安全性検査・解析し、欠落または不正なら起動を失敗させる。
- 解析結果はPPTX内容のSHA-256でキャッシュする。
- `pptx_create_visual_deck` は、既定テンプレートが設定されている場合に自動的にブランドVisual Deckへ切り替える。
- 添付テンプレートの明示指定、既定テンプレート、テンプレートなしの順序をツール入力で区別する。
- 初回案内はMCPサーバー指示へ注入し、LibreChatの固定ウェルカム表示にはしない。

## 結果

利用者はテンプレート指定なしで組織標準の資料を作成できる。OSSのコード、テストデータ、Dockerイメージには企業固有資産が入らず、別組織も同じ機構を利用できる。初回案内の表示はモデルがMCPサーバー指示へ従うことに依存するため、通しE2Eで対象モデルごとに確認する。
